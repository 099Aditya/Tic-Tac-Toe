# 🎮 Tic-Tac-Toe Game (X-O)

A fully responsive, browser-based **Tic-Tac-Toe** game built using **HTML, CSS, and JavaScript**. This project demonstrates core web development skills like DOM manipulation, event handling, UI design, and game logic implementation.

## 🔧 Features

* 3x3 classic Tic-Tac-Toe board
* Interactive turn-based gameplay
* Win and draw detection with real-time UI updates
* New game & reset functionality
* Clean, modern, and responsive design

## 💻 Tech Stack

* **HTML5** – Structure and markup
* **CSS3** – Responsive, styled interface
* **JavaScript** – Core logic and interactivity
